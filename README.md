# 🌍 Wanderlust — Travel & Adventure Hub

Uma plataforma web moderna, elegante e de alta conversão para a agência de viagens de luxo e aventuras **Wanderlust & Co.**. O projeto foi concebido para oferecer uma experiência imersiva ao usuário, combinando um design visual sofisticado com funcionalidades práticas como busca de viagens, filtros dinâmicos de destinos, agendamento de pacotes online e área de acesso ao cliente.

![Wanderlust Banner](https://images.unsplash.com/photo-1507525428034-b723cf961d3e?auto=format&fit=crop&w=1200&q=80)

---

## 🚀 Funcionalidades Principais

- **Hero Section Imersiva:** Apresentação visual com background dinâmico e métricas de impacto (viajantes atendidos, países cobertos e avaliação média).
- **Barra de Pesquisa Flutuante:** Widget interativo para filtrar viagens por destino, data desejada e quantidade de passageiros.
- **Catálogo de Destinos com Filtros Dinâmicos:** Filtro em tempo real por categorias (*Praias*, *Montanhas* e *Cidades Urbano*) sem recarregamento da página.
- **Sistema de Reserva Online:** Modal dinâmico para captura de dados do cliente e solicitação de reserva do pacote escolhido.
- **Área do Cliente (Modal de Login):** Interface para autenticação rápida de usuários cadastrados.
- **Seção institucional "Sobre Nós":** Destaque para os diferenciais da agência, como *Garantia & Segurança*, *Concierge 24/7* e *Turismo Sustentável*.
- **Mural de Depoimentos:** Avaliações de clientes reais acompanhadas de classificação em estrelas.
- **Captura de Newsletter:** Formulário para captação de e-mails com ofertas exclusivas e cupons de desconto.
- **Notificações Toast Personalizadas:** Alertas em tempo real construídos em JavaScript para dar feedback a cada ação do usuário.

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estrutura semântica e acessível.
- **[Tailwind CSS](https://tailwindcss.com/):** Framework CSS utilitário para estilização responsiva e ágil com paleta de cores customizada.
- **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Lógica interativa de busca, filtros de categorias, modais e sistema de notificações.
- **[Font Awesome (v6)](https://fontawesome.com/):** Biblioteca de ícones vetoriais.
- **[Google Fonts](https://fonts.google.com/):** Tipografia *Plus Jakarta Sans* para uma leitura clara e moderna.
- **[Unsplash API/Images]:** Fotografias de altíssima resolução com curadoria para turismo e paisagens paradisíacas.
